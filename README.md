# BMI 461: Fall 2026 Sprint Projects

Welcome to BMI 461! Follow the step-by-step instructions below to create your workspace, add Dr. Scotch, and submit your project updates throughout the semester.

---

**1. Getting Started (Repository Setup)**

1. Click the green **Use this template** button at the top right of this page and select **Create a new repository**.
2. Set the options as follows:
   - **Owner:** Select your personal GitHub account.
   - **Repository Name:** `BMI461-Sprint[N]-[YourLastName]` (e.g., `BMI461-Sprint1-Smith`).
   - **Visibility:** Select **Private** *(Required: Do not make your code public)*.
3. Click **Create repository**.

---

**2. Grant Dr. Scotch Access**

To allow Dr. Scotch to review and grade your work:

1. Open your new private repository on GitHub.
2. Go to **Settings** > **Collaborators** (under the "Access" section on the left sidebar).
3. Click **Add people** and invite the following handles:
   - Instructor: `ZooPhy`
4. Assign them **Admin** or **Write** permissions.
